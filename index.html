Stub Signature-Based Efficient Public Data Auditing System Using Dynamic Procedures in Cloud Computing

About

Cloud data storage has become a cornerstone of the IT industry, offering scalable, flexible, and cost-effective services that allow users to store and manage data without the need for personal storage infrastructure. However, the widespread use of cloud services introduces significant security concerns, particularly regarding data privacy and integrity, as outsourced data may be vulnerable to unauthorized access by malicious insiders or hackers. To mitigate these risks, a partial signature-based data auditing system is proposed, employing cryptographic techniques like homomorphic encryption and hash functions to ensure secure sharing and integrity verification. This system enables dynamic operations on outsourced data, performing integrity checks at regular intervals to detect tampering attempts, while also reducing the computational costs typically associated with data auditing processes. The proposed approach demonstrates promising security enhancements and operational efficiency, making it suitable for real-world cloud storage applications based on simulation outcomes involving dynamic data blocks and sub-blocks.
